El proyecto consiste en un analizador léxico, sintáctico y traductor de codigo el cual está basado en un lenguaje personalizado de funciones e instrucciones básicas ('leer', 'escribir', 'asignacion').

para ejecutarlo se debe realizar lo siguiente:
1. ¡¡Abrir unicamente la carpeta "proyecto"!! en el Visual Studio Code, es fundamental para que se reconozcan bien las rutas de los archivos.
2. copiar desde el archivo "Ejemplo N°" los datos y pegarlo en el archivo input.txt.
3. Guarda con "Ctrl + S" los cambios realizados
4. Posicionarse en el archivo 'index.js' y ejecutar (F5) seleccionando la opción "Node.js" 

Al hacer esto, la consola mostrara el arbor sintáctico, la tabla de tokens y la intrepretación (traducción) del codigo generado.
